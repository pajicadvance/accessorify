Bugfix release for 1.20.1 to fix the following issues when running the mod on Forge via Sinytra Connector:
- Downgraded required Fabric Loader version to 0.16.14 from 0.17.2.
- Added compatibility for Sodium Dynamic Lights on Forge 1.20.1.
  - Make sure to tick on "Dynamic entity lighting" in video settings.
  - *Sodium Dynamic Lights is supported ONLY on Forge 1.20.1. For all other versions use LambDynamicLights!*
